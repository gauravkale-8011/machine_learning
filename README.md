# 🧠 Machine Learning Practice Repository

This repository contains my hands-on practice and implementation of core Machine Learning concepts using Python and Jupyter Notebook.

The goal of this repository is to build strong fundamentals by implementing algorithms and preprocessing techniques from scratch and using libraries like NumPy, Pandas, and Scikit-learn.

---

## 📚 Topics Covered

- ✅ Simple Linear Regression (from scratch implementation)
- ✅ Multivariate Analysis
- ✅ Handling Missing Numerical & Categorical Data
- ✅ KNN Imputer
- ✅ Encoding Categorical & Numerical Variables
- ✅ Column Transformer
- ✅ Feature Engineering & Feature Construction
- ✅ Train-Test Splitting
- ✅ End-to-End ML Toy Project
